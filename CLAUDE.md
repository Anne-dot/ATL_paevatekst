## 🎯 Quick Reference

### Before Any Code/Documentation
1. ✅ Discuss approach and present options
2. ✅ Get explicit approval before proceeding
3. ✅ Confirm understanding and summarize decisions
4. ✅ Reference these principles

### Development Approach
- ADHD-friendly, clear, well-documented
- MVP-first with progressive enhancement
- No silent failures - all errors visible
- Step-by-step implementation with approval

### Communication Style
- Ask when unclear, never assume
- Present trade-offs and alternatives
- Wait for confirmation at key decision points
- Be transparent about limitations and bugs
